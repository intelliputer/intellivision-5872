## Parts not present as exact data sheets in this catalogue

- **RO-3-9506-010** (Intellivision II EXEC): not listed; it was introduced after the original split-EXEC ROM arrangement covered by this catalogue. Its available replacement documentation is listed above.
- **AY-3-8914** (sound): not listed in this catalogue. Its exact technical-information pages are listed above. [AY-3-8910/AY-3-8912 PSG family reference](AY-3-8910_AY-3-8912_PSG_family_reference.pdf) remains related background only, not an assertion that it is pin- or behavior-compatible with AY-3-8914.
- **AMI AM9111BPC** parts: not GI components, so they are outside this GI catalogue.
